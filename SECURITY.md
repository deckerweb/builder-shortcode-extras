# Security / Sicherheit

## English

Report vulnerabilities privately through [Security → Advisories → Report a vulnerability](https://github.com/deckerweb/builder-shortcode-extras/security/advisories/new) in this host repository, including issues in its bundled deckerweb Library or Updater. Include plugin/component versions, WordPress/PHP versions, a minimal reproduction and expected impact. Never include passwords, tokens or personal user data. Use public Issues for ordinary bugs, without vulnerability details. David Decker assesses reports and coordinates fixes and disclosure; no fixed response deadline is promised. Use the latest stable release.

## Deutsch

Melde Sicherheitslücken vertraulich über [Security → Advisories → Report a vulnerability](https://github.com/deckerweb/builder-shortcode-extras/security/advisories/new) in diesem Host-Repository, auch für die eingebettete deckerweb Library oder den Updater. Nenne Plugin-/Komponentenversionen, WordPress/PHP-Versionen, eine minimale Reproduktion und die erwarteten Auswirkungen. Gib keine Passwörter, Tokens oder personenbezogenen Benutzerdaten weiter. Normale Fehler gehören in öffentliche Issues, ohne Sicherheitsdetails. David Decker prüft Meldungen und stimmt Korrekturen und Offenlegung ab; es wird keine feste Reaktionsfrist versprochen. Verwende die aktuelle stabile Version.
