# Versions- und Datenkonventionen

[English](CONVENTIONS.md) · [Deutsch](CONVENTIONS-de.md)

Versionsnummern verwenden Haupt-, Neben- und Fixversion. Neue Funktionen erhöhen die Nebenversion; kompatible Korrekturen die Fixversion. Inkompatible Änderungen benötigen eine Hauptversion und klare Hinweise. Stabile GitHub-Tags tragen das Präfix v. WordPress installiert das Paket builder-shortcode-extras.zip. Generatorwerte bleiben nur im aktuellen Browserdokument. BSE speichert keine Einstellungen. Library-Optionen und Installationsvermerke liegen unter deckerweb_library_settings_v1 und deckerweb_library_installed_v1, je Website beziehungsweise Netzwerk. Temporäre Library-Caches und Aktionssperren sowie der repositorybezogene BSE-Updater-Cache werden ausschließlich im dokumentierten eigenen Umfang bereinigt. Daten anderer Plugins bleiben erhalten.
