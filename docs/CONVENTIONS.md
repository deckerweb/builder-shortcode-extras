# Release and data conventions

[English](CONVENTIONS.md) · [Deutsch](CONVENTIONS-de.md)

Versions use major, minor and patch components. Features increase the minor version; compatible fixes increase the patch. Breaking changes require a major version and clear notices. Stable GitHub tags use a v prefix. WordPress installs builder-shortcode-extras.zip. Generator drafts live only in the current browser document. BSE stores no settings. Library preferences and install records use deckerweb_library_settings_v1 and deckerweb_library_installed_v1, per website or network. Temporary Library caches/action locks and the repository-specific BSE updater cache are removed only within their documented ownership. Foreign plugin data remains.
