# Prüfungen und Kompatibilität

[English](TESTING.md) · [Deutsch](TESTING-de.md)

Die Helfer wurden unter WordPress 6.7, 7.1.2 und 7.1.3 mit PHP 8.4.5 geprüft: Datumsangaben, Inhaltseinbettung, Zugriffsschutz, Shortcode-Registrierung, Kopiergenerator, Update-Metadaten, Netzwerkaktivierung und Berechtigungen in einer echten Multisite. Kommerzielle Builder wurden über repräsentative Adapterfälle geprüft; lizenzierte Builder-/Theme-Installationen wurden nicht vollständig zertifiziert. PHP 8.0 ist die deklarierte Mindestversion, wurde in diesem Prüfstand aber nicht als echte Laufzeit ausgeführt. Unterstützte Integrationen sollten im vorgesehenen Website-Kontext getestet werden.
