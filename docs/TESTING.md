# Checks and compatibility

[English](TESTING.md) · [Deutsch](TESTING-de.md)

Helpers were checked on WordPress 6.7, 7.1.2 and 7.1.3 with PHP 8.4.5: dates, content embedding, access controls, shortcode registration, the copy generator, update metadata, network activation and permissions in an actual multisite. Commercial builders were covered through representative adapter cases; licensed builder/theme installations were not fully certified. Version 1.3.1 requires PHP 8.1 and was also checked with PHP 8.1.29 on WordPress 6.7 and 7.1.3. Test supported integrations in their intended website context.
